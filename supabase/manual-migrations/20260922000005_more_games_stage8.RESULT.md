## Incident during step 4 (corrected in step 6, live for about ten minutes)

The first version of the era RPC file re-created the two ALL-TIME sweep
functions from the 20260804 bodies, which predate the §226 trophy epoch
(`db.day >= '2026-07-29'`, applied 2026-08-20). The all-time board briefly
counted pre-launch sweeps: BMT 97/32 instead of 46/17, and two pre-epoch
accounts (NancyPants, johnnyauer) appeared. The snapshot comparison caught it;
step 6 re-applied the trophy-epoch bodies verbatim and the board matches the
snapshot again. The repo file now carries those bodies, so re-running it is
safe. Lesson recorded in the plan: an RPC re-creation must start from the
LATEST applied version of each function, not from the file that introduced it.
