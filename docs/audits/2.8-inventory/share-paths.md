# 2.8 inventory — share paths ×3 (web, iOS, Android)

Date: 2026-10-09. Read-only grep audit, no builds or tests. Paths relative to `apps/web/` (web), `apps/ios/Wordocious/Sources/` (iOS), `apps/android/app/src/main/kotlin/com/wordocious/app/` (Android). Admin excluded.

**What each platform's share pipeline is.**
- **Web** renderer: canvas PNG. `lib/share-image.ts:1928` `generateShareImage()` (game cards, Daily Sweep, Puzzles Sweep, Today's progress), `lib/vs-share-image.ts:145` `generateVsShareImage()` (VS), `lib/share-canvas.ts` (shared draw helpers, `loadShareImage`, `drawCastWordmark`), `lib/achievement-share.ts:13` `shareAchievementCard()` (badge card). Text path: `lib/share-utils.ts:275` `shareResult()` (emoji grid + caption, `generateEmojiGrid` at :29). Leaderboard/profile/streak cards: `lib/leaderboard-share-flow.ts` → `generateShareImage` with inputs from `lib/leaderboard-share.ts`.
- **iOS** renderer: SwiftUI `ShareCardView` rendered to PNG. `Sources/ShareService.swift:15` `ShareService.share(...)` (text or image chooser, `ShareVariantSheet.swift:21`), `ShareKit.swift` (tray, soft number, PNG naming at :544), `LeaderboardShare.swift:1119` family, `DailySweepShare.swift:245-286`.
- **Android** renderer: `data/ShareImage.kt:295` `share()` (game cards, with `shareBitmap` :685, `shareVs` :823), `data/ShareHelper.kt:101` `share()` (text), `:168` `shareImages()`, `:185` `shareImage()`. Leaderboard `data/LeaderboardShare.kt:942-1133`, Daily Sweep `data/DailySweepShare.kt:151-287`.

Counts are rows (one per share entry point). "Image" = PNG card; "text" = caption or emoji grid. Where a game's post-game screen has a share button it is the shared `FinishedDock`/`FinishedShareCTA`/`ShareResultsCandy` (one button for all games).
