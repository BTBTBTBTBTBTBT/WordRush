# Accessibility review, 10-16 (read-only, code-level)

Scope: the UI added or changed 10-15 / 10-16 on iOS (SwiftUI), Android (Compose) and web: the one-image podium, Friends game cards (design A), the Home headline slot, the costumed Flawless / Sweep celebrations, the Android family confirm sheets, the night share cards' share flow and the new iOS share sheet (`ShareSheetV2.swift`, untracked in the working tree). Static read of the code, no builds; contrast ratios computed from the hex values in the source (WCAG AA: 4.5:1 body, 3:1 for 18 pt / 14 pt bold). Ranked by impact. "Intentional" = a design rule in the file explains it; the fix is then optional.

## High

1. **FIXED 10-16** — **Web Sweep / Flawless celebration is not keyboard-operable as a modal.** (`aria-modal`, Escape closes, Tab trap inside the dialog, `autoFocus` on Close, focus returns to the opener; the float math was not touched.) `apps/web/components/effects/sweep-celebration.tsx:166` sets `role="dialog"` but no `aria-modal`, no Escape handler, no initial focus and no focus trap, so Tab leaves the overlay into the page behind it and Escape does nothing (the house pattern exists in `components/ui/family-action-menu.tsx:108,129` and `components/modals/menu-modal.tsx:54,80`). Smallest fix: add `aria-modal="true"`, a `useEffect` keydown listener that calls `onClose` on Escape, and `autoFocus` on the Close `QuietButton` (line 300).

2. **FIXED 10-16** — **Friends game rows never tell a screen reader whose turn it is (all three apps).** (core `gameRowLabel(kind, word, yourTurn)` + Swift / Kotlin ports, pinned by `rowLabel` in friend-cards-fixtures.json; used by all three row labels.) The YOUR TURN / WAITING chips are hidden from assistive tech and the row's label is only "Title, word": web `friend-cards.tsx:191`, iOS `FriendCardsView.swift:160,186,198`, Android `FriendCardsView.kt:242`. Most `tileWord` strings start with "Waiting for…" or "Your turn…", but RPS ("Pick rock, paper or scissors"), Coin ("Call heads or tails"), Pass ("Your guess (2 of 6)") and Ghost ("Start the word: add a letter") do not (`packages/core/src/friend-cards.ts:83-93`). Smallest fix: one core helper (`gameRowLabel(tile)` → `"${title}, ${word}, your turn"` / `", waiting on them"`) used by the three labels, pinned by the friend-cards fixtures.

3. **FIXED 10-16** — **Web winner intro ignores the in-app Reduce Motion toggle.** (the three podium rules duplicated under `[data-reduced-motion="true"]`.) `apps/web/app/globals.css:1769-1773` calms `.podium-glow` / `.podium-sparkle` / `.podium-crown` only under `@media (prefers-reduced-motion: reduce)`; the app's own `[data-reduced-motion="true"]` switch (which the celebration kit honors at lines 1795-1796 and 1812) is not covered, so the glow scale-in, sparkles and crown drop still play for players who turned motion off in Settings. Smallest fix: duplicate the three rules under `[data-reduced-motion="true"] …`. iOS (`FinishPages.swift:1082-1096`, `947`) and Android (`BoardPodium.kt:392 WTheme.calmMotion`) are correct.

4. **FIXED 10-16** — **White lettering on the Sweep overlay fails AA on web.** (kicker + summary line now use the moment's dark ink per look: gold `#5A3200` 5.4-8.0:1, pink `#5a1038` 3.8-8.2:1, indigo `#1e1b4b` 3.6-8.0:1 on the top / mid stops; iOS already draws them in `accentText`.) `sweep-celebration.tsx:173` ("DAILY" / "PUZZLES" kicker, 12 px) and `:249` ("All 8 Dailies done today!", 14 px) are white on the gold overlay (`LOOKS.sweep.overlay`, lines 331-333): 1.4:1 on the top tint `#FFD678`, 2.0:1 at mid `#F5A524`. Flawless pink is 3.5:1 (passes only as large text), More-games indigo 4.5:1 passes. The `INK_SHADOW` text shadow does not count toward the ratio. Smallest fix: put the two lines on the moment's dark ink (`#5A3200` for gold, as the chips already do) or add a 40% `#3B1A78` pill behind them. Android draws these in `WTheme.text`/`ink` by theme (`SweepCelebration.kt:310`), check iOS `SweepCelebrationView.swift:99` on the same pass.

## Medium

5. **FIXED 10-16** — **Resign flip drops focus (all three).** (web `autoFocus` Keep + Escape → Keep + focus back on the flag; iOS `@AccessibilityFocusState` keep-/flag-ids on `confirming`; Android `FocusRequester` on Keep in a `LaunchedEffect`.) Tapping the flag unmounts it and swaps in Keep / Resign; nothing receives focus, so a keyboard / VoiceOver / TalkBack user lands on the body or the previous element. Web `friend-cards.tsx:176,87-120`; iOS `FriendCardsView.swift:200-230`; Android `FriendCardsView.kt:238-239,335-357`. Smallest fix: web `autoFocus` on Keep plus Escape → `onKeep`; iOS an `@AccessibilityFocusState` set to Keep when `confirming` changes; Android a `FocusRequester` on Keep requested in a `LaunchedEffect(confirming)`.

6. **FIXED 10-16 (hit areas only, visuals unchanged)** — **Hit targets under 44 pt / 48 dp on the game rows.** (flag 44 × row, Keep / Resign 44 tall, "+N more" 44 tall via negative margins / `padding(-)` / `requiredSize`; Android "More for X" 36 dp left as is.) Resign flag 30 × 30 (web `friend-cards.tsx:77`, iOS `FriendCardsView.swift:261`, Android `FriendCardsView.kt:322`); Keep / Resign 26 pt (web `:105,114`, iOS `:213,222`) and 28 dp (Android `:346,351`); "+N more" 28 pt (web `:229`, iOS `:240`); Android "More for X" round button `tap = 36.dp` (`FriendCardsView.kt:162`). **Intentional** (the 50 pt slim row, docs/design/review/friends-cards-1015/SPEC.md), but the visuals can stay as they are: grow only the hit area to the row height (web: `height: ROW_H` on the flag button and `minHeight: 44` with `padding` on Keep / Resign; iOS: `.frame(width: 44, height: 50).contentShape(Rectangle())` outside the 22 pt coin; Android: `Modifier.sizeIn(minWidth = 48.dp, minHeight = 48.dp)` before `tileClickable`, or `minimumInteractiveComponentSize()`).

7. **FIXED 10-16 (title + word only; chips stay fixed by design)** — (iOS `GameRowText` = @ScaledMetric + `.dynamicTypeSize(...accessibility1)`, 1:1 with `fixedFont` at Default; Android title/word read fontScale capped 1.5x inside `FixedFont`, row `heightIn(min = 50.dp)`, WAITING / YOUR TURN 10 / 10.5 sp → 11.5 sp (fits the 22 / 24 dp capsules, ~15.7 dp line); web rows are px but scale with browser zoom, so untouched.) **Game-row type is fixed-size on iOS and Android.** Title (12.5), word (11), chip (10 / 10.5), Keep / Resign (11), "+N more" (11.5) all use `Brand.fixedFont` (`FriendCardsView.swift:148-151,178,195,207-208,213,222,240`) / `FixedFont` (`FriendCardsView.kt:144,199,237`), so Larger Accessibility Sizes do nothing for the only text that says what game it is and whose move. **Intentional** for the chips (file header, "chip and row type are fixed size"). Smallest fix: keep the chips fixed but let the title and word scale, capped (iOS `.dynamicTypeSize(...DynamicTypeSize.accessibility1)` on those two `Text`s; the row already has `minHeight: 50`, not a fixed height). Android's row is `height(50.dp)` (`:233`), so there use `heightIn(min = 50.dp)` with the same cap. Also 10 sp WAITING / 10.5 sp YOUR TURN are below Android's 12 sp floor; if they stay fixed, 11.5 sp is still inside the 22 / 24 dp capsules.

8. **FIXED 10-16** — **WAITING chip ink is under 4.5:1 on the light Friends surface (web).** (`var(--fr-row-sub, #604f7a)`: 5.1:1 on the chip over the card wash; night keeps `--fr-row-sub`.) `FR_LOOK.rowSub` `#7a6a95` over the 14 % purple wash is 3.9:1 at 10 px / 800 (`friend-cards.tsx:162`, `lib/friends-look.ts:33`). Night surfaces are fine (`--fr-row-sub` = `--color-text-muted` over `rgba(255,255,255,0.08)`; the night YOUR TURN word `#ffd45a` is 12.9:1). YOUR TURN `#5A3200` on gold is 6.0-8.9:1. Smallest fix: `--fr-chip-ink` (`#5a2342`, already defined) for the WAITING text, or `#6a5a85`.

9. **OPEN (share-sheet owner)** — **iOS share sheet: the card carousel reads "Classic card" only.** `ShareSheetV2.swift:363` labels each rendered PNG by its title, so a VoiceOver user cannot hear the score / streak the card carries or whether the spoiler toggle changed it. Smallest fix: pass the core card's text (the `ShareSheetCard` subtitle / share text that `shareSheetModel` already builds) as the `accessibilityLabel`, and `accessibilityValue("\(i + 1) of \(count)")`.

10. **OPEN (share-sheet owner)** — **iOS share sheet: the variant pill segments are 36 pt tall** (`ShareSheetV2.swift:451`) and the "Copied" / "Saved" toast is never announced (`:287-296,607-617` is `.combine` with no `UIAccessibility.post(.announcement)`), so VoiceOver users get no confirmation that Copy link worked. Smallest fix: `.frame(height: 44)` on the segment (the pill can stay 36 visually with `.padding(.vertical, -4)` outside the background), and `UIAccessibility.post(notification: .announcement, argument: text)` inside `show(_:)`.

11. **FIXED 10-16 (token only)** — **Thanksgiving palette: the accent is not a text color.** (`surfaces.accentText #943F10` added to the registry ×3 — 4.9-6.2:1 on the light walls, 7.1:1 under white — and pinned by season-contrast.test.ts; wiring the callers to it is the before-Nov-14 follow-up.) `packages/core/src/season-registry.json` thanksgiving `accent #F0824A`: 2.6:1 under white text, 2.1:1 as text on `wallLight #F6E3CC`; `buttonTint #D62A4A` is 4.9:1 under white (passes) and 3.9:1 as text on the light wall (large text only). `quietTint #7E2A5B` passes everywhere (7.1-8.9:1), wheat on the dark wall 11.8:1. Smallest fix: wherever a season `accent` becomes ink or a button fill (the `ThemeKit.accentPalette` callers), use `buttonTint` for fills and `quietTint` for ink on the light walls; or darken the accent to `#C9601F` (4.6:1 under white). Pre-activation (ready = false), so this is a before-Nov-14 item.

## Low

12. **Podium name link is a small target on web.** `podium.tsx:151-162`: the `Link` is as tall as the bubble lettering (≈14-20 px). The sr-only place summary (`:249`) and the figure button (`:236-240`) are complete, so this is reachability only. Smallest fix: `padding: '6px 0'` on the Link. Podium labels (core `podiumPlaceLabel` / `podiumOpenSpotLabel`), decorative art (`aria-hidden`, `clearAndSetSemantics`, `.accessibilityHidden`) and reading order (1st, 2nd, 3rd in DOM / tree order) check out on all three; the crown hat is part of the mascot art and "First place" already says it.

13. **Web "+N more" button has `aria-expanded` but Android's does not expose a state.** Android `FriendCardsView.kt:202` bakes "collapsed" into the label (fine, but it never says "expanded"). Smallest fix: `stateDescription = if (expanded) "Expanded" else "Collapsed"` in the semantics, label without the word.

14. **Android family confirm sheets** (`FamilyActionMenu.kt:353-443`): title is a heading via `BubbleText`'s `clearAndSetSemantics` (`BubbleText.kt:201-205`), message is 14.5 sp (scales), Cancel then Confirm order matches iOS, `BackHandler` / scrim dismiss come from `SoftModalSheet`. One gap: `confirmEnabled = false` also disables Cancel (`:438`), which strands a keyboard / switch user with no way out but the scrim. Smallest fix: `enabled = true` on the dismiss button.

15. **Web Sweep: "Won / Total Time / Total Pts" labels are 10 px `--color-text-muted`** (`sweep-celebration.tsx:260`); fine on the soft pills in light, check the night pill mix. The per-game W / L badges rely on `WinLossBadge`'s own label; Android merges "won / lost" into the row (`SweepCelebration.kt:355`) which is the better pattern, iOS `SweepCelebrationView.swift:211-214` should carry the same `accessibilityLabel`.
