# Bios and tracked links (setup task S3)

One line per channel, built on "18 daily games. One score." Each channel's link is its own tracked /go link, so Marketing shows clicks and signups by channel. All of these slugs exist in Marketing > Channels (linkedin, producthunt and press were added Oct 14). Character counts are for the bio text only. No emoji.

How the links work: wordocious.com/go/<slug> counts the click, sets a 30-day first-touch cookie, then lands on wordocious.com. Any brand-new account created within 30 days is credited to that slug. Do not shorten or alter these links.
