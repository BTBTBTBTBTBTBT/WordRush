# Night art session — 2026-10-03 (ChatGPT, founder's Plus account)

Queue: `NIGHT-ART-QUEUE.md`. Every image this time is a **full-size ChatGPT download** (1254² squares,
~1950×800 letterings, 1536×1024 sheets); no pane captures and nothing upscaled. Keyed with `key-capture.py`
in its new `native` / `native-all` modes (keep the source resolution, just trim; `native-all` also keys every
enclosed key-colored pocket, for lettering). Raw downloads were kept in the session scratchpad only.

Pipeline that worked: prompt typed into the focused ProseMirror box + Return; a small in-page helper waits for a
new `Generated image` whose `src` is stable, then `fetch(blob) → <a download>` saves it to ~/Downloads as
`wart-<name>.png`, which is moved out and keyed. Same-chat follow-ups ("Now ONLY character 4…") keep a style
reference in context; one character per prompt, every drawing a new expression.
