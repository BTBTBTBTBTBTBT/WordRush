3 · Numbers

Digits in the same style

For the number games (Sudocious, Sequence counts, timers on tiles): the same tiles carry digits 0 to 9. Sudoku gets one more state, the given clue, a plain white tile with dark purple digits, so it reads as fixed. Scores, streaks and timers use the same soft rounded numbers as the header controls, never the gradient lettering.

The friendly 3D icon family from the tab bar, used for every header control on every page: Home (streak, shields, help, settings) and the game screens (home, sound, help). No circles behind them, plain rounded numbers, a full 44-point tap area, and the squish when pressed.

How it gets built

  1. One shared tile per platform (web, iPhone, Android), drawn in code so it stays crisp at every size. Every word game uses it: Classic, Six, Seven, QuadWord, OctoWord, Succession, Deliverance, Gauntlet, ProperNoundle, Muddle, the VS boards and the share previews.
  2. Boards fill the screen. On every game, the board takes all the space between the title and the keyboard: as wide as the screen allows (a small margin each side) and centered in the height that is left, so tiles get as big as possible. Multi-board games (QuadWord, OctoWord, Succession) size their whole grid the same way.
  3. The keyboard switches to the same tile style, colored after each reveal.
  4. One motion kit with the timings in the table above, so every game animates the same way.
  5. Numbers roll out to Sudocious first, then anywhere digits sit on tiles.
  6. The WORDOCIOUS header (option A) full width on all three apps.
  7. Less white everywhere. Every card on every menu takes a soft wash of its own accent color instead of plain white (the game cards, Word of the Day, VS Battle, the Leaderboard and Stats cards).
  8. The tab bar docks to the bottom edge with a soft lilac tint; content ends above it.
  9. Header controls use the soft 3D icons everywhere (home, sound, help, settings, streak, shields), with no circles behind them.
