# Speech bubble family (FRIDAY-QUEUE item 19)
`out/`: `bubble-tail-left|right|top`, `pager-dots` (first dot gold = current), `typing-bubble` (three dots, animate in code),
`pill-bubble` (short labels); the same set `*-halloween` (black-violet candy, orange rim, tiny bats). Text is live; nine-slice the
bubbles at the corner radius (~22% of height) and keep the tail as its own slice. Nothing is outlined or boxed (no-bordered-boxes rule).
