# Codebreaker chip tiles (FRIDAY-QUEUE item 31)

`out/`: `chip` (fixed size, answer slot reserved), `chip-selected` (violet glow), `chip-solved` (gold slot filled),
`chip-used` (grey), `badge-purple` / `badge-gold` (count badge, top-right corner), `slot-empty` / `slot-filled`
(standalone answer slot for the "-> X" part), `arrow`, `tray` (wide base), `sparkle` (pop on solve), `check-badge`.
Letters and counts are drawn live (Nunito Black). `chips-demo.png` = a tray of six. Chip size is identical in every
state so the board never resizes. The selected glow was despilled by hand (cyan key fringe removed).
